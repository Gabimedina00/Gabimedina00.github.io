Conectar este dispositivo (una sola vez)

Solo quien tenga esta clave puede cambiar la página. Sin ella, este panel no puede guardar nada.

  1. Entrá a crear clave en GitHub (con tu cuenta de GitHub).
  2. Nombre: iBros web. En Resource owner elegí iBrosTechnology. Vencimiento: No expiration.
  3. En Repository access elegí Only select repositories y marcá los dos: iBrosTechnology.github.io y ibros-registro.
  4. En Permissions, buscá Contents y poné Read and write.
  5. Tocá Generate token, copiá la clave y pegala acá abajo. Si GitHub dice que la clave espera aprobación, aprobala vos en la organización: Settings → Personal access tokens → Pending requests.

Activar el registro privado

El registro guarda datos de clientes y precios, así que va en un repositorio privado aparte, que solo vos podés ver. La página pública nunca lo lee.

  1. Creá el repositorio privado: crear ibros-registro. Que quede Private.
  2. En GitHub, abrí tu clave (Fine-grained tokens → iBros web → Edit) y en Repository access sumá ibros-registro. Guardá.
  3. Volvé acá y tocá Probar de nuevo.

Activar reseñas en el panel

Las reseñas que escriben los clientes en la página se guardan en Supabase (gratis), donde solo vos podés leerlas. Nada se publica solo: vos elegís cuáles van a la página.

  1. Entrá a supabase.com y creá tu cuenta (podés usar la de GitHub). Tocá New project, nombre ibros, región South America (São Paulo), inventá una contraseña de base de datos (no la vas a usar acá) y creá el proyecto.
  2. En el proyecto, abrí Project Settings → Data API (o API Keys) y copiá la URL y la clave publishable (o anon public). Pegalas acá. Nunca uses la clave secret ni service_role.
  3. Escribí tu mail. Es el usuario con el que vas a entrar a leer las reseñas.
  4. En Supabase abrí SQL Editor → New query, pegá este texto y tocá Run. Crea la tabla y deja que solo tu mail la lea.
  5. En Authentication → Users tocá Add user → Create new user, con tu mail y una contraseña nueva, y marcá Auto Confirm User.
  6. En Authentication → Sign In / Providers apagá Allow new users to sign up y guardá. Así nadie más puede crearse un usuario.
  7. Escribí la contraseña del paso 5 y tocá Conectar.
